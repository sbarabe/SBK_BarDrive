# Generated API documentation

The files in `docs/html` are generated from the current SBK_BarDrive sources
with the root-level `Doxyfile`. Do not edit the generated HTML manually.

To regenerate the documentation, run this command from the repository root:

```powershell
& "C:\\Program Files\\doxygen\\bin\\doxygen.exe" Doxyfile
```

If Doxygen is already on your `PATH`, use `doxygen Doxyfile` instead.
